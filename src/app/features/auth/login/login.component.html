El TypeScript — login.component.ts imports en el decorador imports: [ReactiveFormsModule, RouterLink, CardComponent, ButtonComponent, InputComponent] Como el componente es standalone (sin NgModule), necesita declarar explícitamente todo lo que usa. Es como los using en C# — si no lo importas, Angular no sabe que existe. - ReactiveFormsModule — habilita [formGroup] y formControlName en el HTML - RouterLink — habilita el atributo routerLink en los - Los tres componentes propios que creamos --- FormBuilder private readonly fb = inject(FormBuilder); form = this.fb.group({ email: ['', [Validators.required, Validators.email]], password: ['', [Validators.required, Validators.minLength(6)]] }); FormBuilder es un helper de Angular para crear formularios. fb.group() crea un FormGroup — un objeto que agrupa campos relacionados. Cada campo se define como: nombreCampo: [valorInicial, [validadores]] Los validadores corren automáticamente cada vez que el usuario escribe. Si el email no es válido, form.controls.email.invalid es true inmediatamente. --- Signals para estado local loading = signal(false); error = signal(''); Dos signals simples: - loading — controla el spinner del botón mientras espera el backend - error — muestra el mensaje de error si el login falla --- onSubmit() onSubmit() { if (this.form.invalid) return; // 1. Valida antes de llamar al backend this.loading.set(true); // 2. Activa el spinner this.error.set(''); // 3. Limpia errores anteriores const { email, password } = this.form.value; this.authService.login({ email: email!, password: password! }) .subscribe({ next: (response) => { // 4. Si el backend responde OK this.authService.saveSession(response); this.router.navigate(['/dashboard']); }, error: () => { // 5. Si el backend responde con error this.error.set('Email o contraseña incorrectos'); this.loading.set(false); } }); } El ! después de email y password es un non-null assertion de TypeScript — le dices al compilador "sé que este valor no es null porque ya validé el formulario arriba". .subscribe() es cómo consumes un Observable en Angular.
